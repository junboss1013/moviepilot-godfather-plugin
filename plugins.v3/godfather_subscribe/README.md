# 教父订阅转存（godfather_subscribe）

一个 **MoviePilot V2/V3 插件**：定时遍历 MoviePilot 的订阅，用教父站优先找资源并转存到 115 网盘。

> 这是一个**独立插件**，与「教父资源转存」（手动发「片名？」搜索）互不依赖。两者可同时安装。

## 工作流（订阅联动）

```
定时 cron 触发（默认每天 8:00、20:00 各一次）
        │
        ▼
遍历 MoviePilot 订阅列表
        │
        ├─ 类型范围过滤（电影 / 电视剧 / 全部）
        │
        ├─ 电视剧：该季已转存过 → 跳过（按季去重，继续追更）
        │
        ▼
用订阅片名搜索教父站
        │
        ├─ 搜到资源 → 片名+年份校验 → 画质/做种排序
        │       │
        │       ├─ 有 115 分享 → 直接转存 115
        │       └─ 否则 → 磁力按画质+做种选最优 → 115 离线下载
        │       │
        │       ├─ 自动分类到 影视库/电影/片名 (年份)
        │       │            或 影视库/电视剧/剧名 (年份)/Season XX
        │       │
        │       ├─ 电影转存成功 → 结束该订阅（防止主程序重复下载）
        │       └─ 电视剧 → 记录已转存季，保留订阅继续追更
        │
        └─ 搜不到 → 不干预订阅 → 交回 MoviePilot 主程序自身搜索（自动回退）
```

## 关于「优先插件、搜不到回退主程序」

MoviePilot 的订阅搜索是主程序内置的后台链，插件**不能拦截**它。本插件采用的策略是：

- **教父站搜到**：主动转存 115；电影成功后结束订阅 → 主程序不再重复下载，事实上实现"插件优先"。
- **教父站搜不到**：什么都不做，订阅保持原样 → 主程序按自身逻辑继续搜索 → 自然回退。

这是一种"抢占式回退"，不是对主程序搜索的硬拦截。

## 关于追更（细粒度说明）

教父站资源多为**整季/整部打包**，插件的追更粒度是**按季**，不是按集：

- 电视剧订阅转存某季后，会把季号记入进度（插件私有数据 `gf_sub_progress`）；
- 后续定时遍历时，已转存的季直接跳过，只补新出现的季；
- 订阅始终保持激活，以便检测新季。

## 配置项

| 配置项 | 说明 |
|---|---|
| 启用插件 | 打开后定时服务才会注册 |
| 教父站地址 / 账号 / 密码 | 教父站登录凭据（也兼容旧版 Cookie）；密码仅存本机 |
| 115 网盘 Cookie | 必填，含 `UID/CID/SEID/KID`，用于转存与离线下载 |
| 浏览器验证(PoW) | 站点有人机验证时用内置浏览器自动完成（需 playwright+chromium） |
| 定时 Cron | 5 段 cron（分 时 日 月 周），默认 `0 8,20 * * *` 即每天 8 点、20 点各一次 |
| 订阅类型范围 | both=电影+电视剧 / movie=仅电影 / tv=仅电视剧 |
| 电影成功后结束订阅 | 默认开；防止主程序重复下载，关闭则保留订阅 |
| 订阅新增时立即尝试 | 默认关；打开后新订阅加入时延迟触发一次（避免与主程序初始搜索竞争） |
| 转存时自动分类 | 在 115 网盘按电影/电视剧建目录，配合 rclone/openlist 挂载供 Emby 刮削 |
| 画质权重 / 做种权重 | 磁力择优的加权系数 |

注册后可在 **设定 → 服务** 中看到 `教父订阅转存（定时遍历订阅）`，支持查看运行状态和手动启动。

## 安装

与「教父资源转存」相同插件源，安装时选择 **教父订阅转存**。V3 用 `plugins.v3/godfather_subscribe`，V2 用 `plugins.v2/godfather_subscribe`。

依赖：`beautifulsoup4`、`requests`、`playwright`（开启 PoW 浏览器验证时需要）。

## 合规提示

请确保你有权访问相关内容并遵守所在地区法律法规及站点条款。插件仅自动化你本人账号的订阅与转存操作，不破解鉴权、不撞库。
